# r3v::pwn

Reverse engineering & binary exploitation research blog.

Built with Jekyll, deployed on GitHub Pages.

## Adding a new post

Create a file in `_posts/` with the format `YYYY-MM-DD-title.md`:

```markdown
---
layout: post
title: "Your Post Title"
date: 2026-05-08
tags: [re, pwn, cve, malware, tool]
---

Your content here in Markdown.
```

Available tags: `re`, `pwn`, `cve`, `malware`, `tool`

Push to `main` and the site deploys automatically.
